### 1. المفاهيم الأساسية (Peruskäsitteet)

| المصطلح بالفنلندية  | الوظيفة والشرح بالعربي                                      | مثال عملي                     |
| ------------------- | ----------------------------------------------------------- | ----------------------------- |
| **Elementti**       | الوسم كاملاً بفتحه وإغلاقه والمحتوى الذي بينهما             | `<p>Teksti</p>`               |
| **Tagi**            | وسم الفتح أو وسم الإغلاق                                    | `<p>` أو `</p>`               |
| **Attribuutti**     | خاصية توضع داخل وسم الفتح لتزويد العنصر بمعلومات إضافية     | `href="..."`, `class="..."`   |
| **Sisältö**         | المحتوى النصي أو البصري الموجود داخل العنصر                 | `Teksti`                      |
| **Juurielementti**  | العنصر الجذر الأساسي الشامل لكل المستند                     | `<html>`                      |
| **Meta-tiedot**     | بيانات خلف الكواليس توضع في الرأس `<head>` ولا تظهر للزائر  | `<meta charset="UTF-8">`      |
| **Responsiivisuus** | تجاوب الصفحة وملائمتها لمختلف الشاشات (الهواتف والكمبيوتر)  | `<meta name="viewport" ...>`  |
| **Semanttinen**     | وسم له معنى دلالي واضح ومحدد بدلاً من استخدام `<div>` العام | `<main>`, `<header>`, `<nav>` |

---

### 2. أنواع عرض العناصر (Elementtien tyypit)

| نوع العنصر                   | سلوك العنصر في الصفحة                                                             | الأمثلة الشائعة                                                                                                 |
| ---------------------------- | --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **Lohkoelementti** _(Block)_ | يبدأ دائماً من سطر جديد ويأخذ عرض السطر كاملاً (100%).                            | `<div>`, `<p>`, `<h1>`-`<h6>`, `<header>`, `<main>`, `<section>`, `<footer>`, `<ul>`, `<ol>`, `<li>`, `<table>` |
| **Rivielementti** _(Inline)_ | لا يبدأ من سطر جديد ويجلس بجانب العناصر الأخرى مستهلكاً المساحة التي يحتاجها فقط. | `<span>`, `<a>`, `<strong>`, `<em>`                                                                             |
| **حالة خاصة**                | عنصر ينزل مع السطر مثل Inline ولكنه يقبل تحديد العرض والارتفاع.                   | `<img>`                                                                                                         |

---

### 3. أنواع مسارات الروابط والصور (Polut)

| نوع المسار              | الشرح والوظيفة بالعربي                                 | مثال عملي                                                           |
| ----------------------- | ------------------------------------------------------ | ------------------------------------------------------------------- |
| **Relatiivinen polku**  | مسار نسبي يشير لملف موجود داخل نفس المشروع أو السيرفر. | `<a href="sivu2.html">`, `<img src="img/kuva.jpg">`                 |
| **Absoluuttinen polku** | مسار مطلق يشير لرابط موقع كامل على الشبكة (URL).       | `<a href="[https://www.metropolia.fi](https://www.metropolia.fi)">` |

---

### 4. خصائص العناصر (Attribuutit)

| الخاصية           | الوظيفة الاستخدام بالعربي                                  | مثال عملي                    |
| ----------------- | ---------------------------------------------------------- | ---------------------------- |
| **`class`**       | اسم فئة لتنسيق مجموعة عناصر معاً بـ CSS أو استهدافها بـ JS | `<div class="kortti">`       |
| **`id`**          | معرّف فريد خاص بعنصر واحد فقط بالصفحة (ممنوع تكراره)       | `<p id="tulostus">`          |
| **`src`**         | مسار جلب ملف الصورة أو الملف الخارجي                       | `<img src="kuva.png">`       |
| **`href`**        | رابط الانتقال للصفحة أو الملف المرتبط                      | `<a href="sivu2.html">`      |
| **`alt`**         | نص بديل يظهر إذا لم تتحمل الصورة ولذوي الاحتياجات الخاصة   | `<img alt="Logo">`           |
| **`lang`**        | تحديد لغة محتوى المستند                                    | `<html lang="fi">`           |
| **`dir`**         | تحديد اتجاه النص (`ltr` يسار ليمين / `rtl` ييمين ليسار)    | `<html dir="rtl">`           |
| **`type`**        | تحديد نوع حقل الإدخال في النماذج                           | `<input type="password">`    |
| **`placeholder`** | نص توضيحي خفيف يظهر داخل الحقل ويختفي عند الكتابة          | `<input placeholder="Nimi">` |
| **`value`**       | القيمة الفعلية المخزنة أو المكتوبة داخل الحقل              | `<input value="Matti">`      |

---

### 5. النماذج والحقول (Lomakkeet)

| العنصر / النوع        | الوظيفة والاستخدام بالعربي                                                                        |
| --------------------- | ------------------------------------------------------------------------------------------------- |
| **`<form>`**          | الحاوية الرئيسية للنموذج (تأخذ خاصية `action` ورابط السيرفر وخاصية `method` مثل `GET` أو `POST`). |
| **`<label>`**         | العنوان النصي التوضيحي المربوط بحقل إدخال معين.                                                   |
| **`type="text"`**     | حقل إدخال نصي عادي.                                                                               |
| **`type="password"`** | حقل إدخال كلمة سر مخفية برمز نجوم/نقاط.                                                           |
| **`type="submit"`**   | زر إرسال بيانات النموذج إلى السيرفر.                                                              |
| **`type="checkbox"`** | مربع اختيار متعدد (يمكن اختيار أكثر من خيار).                                                     |
| **`type="radio"`**    | زر اختيار دائري (يسمح باختيار خيار واحد فقط من المجموعة).                                         |
| **`<button>`**        | زر عملي عام لتنفيذ الأوامر أو الإرسال.                                                            |

---

### 6. الجداول (Taulukot)

| الوسم         | المظهر والوظيفة بالعربي                                                          |
| ------------- | -------------------------------------------------------------------------------- |
| **`<table>`** | الإطار والصندوق الرئيسي الحاوي للجدول.                                           |
| **`<tr>`**    | إنشاء صف/سطر أفقي جديد داخل الجدول (Table Row).                                  |
| **`<th>`**    | خلية عنوان بعمود الجدول، يظهر نصها بخط عريض وفي المنتصف تلقائياً (Table Header). |
| **`<td>`**    | خلية بيانات عادية داخل الصف (Table Data).                                        |

## 7. Listat (أنواع القوائم في HTML)

| Elementti  | Kuvaus (الشرح بالفنلندية)             | الوظيفة والشرح بالعربي                     | Esimerkki                    |
| :--------- | :------------------------------------ | :----------------------------------------- | :--------------------------- |
| **`<ul>`** | Järjestämätön lista (pallomerkit)     | قائمة غير مرتبة (تنقيط)                    | `<ul><li>Kahvi</li></ul>`    |
| **`<ol>`** | Järjestäytynyt lista (numerot)        | قائمة مرتبة بالأرقام (1, 2, 3)             | `<ol><li>Kahvi</li></ol>`    |
| **`<li>`** | Listan yksittäinen alkio              | عنصر واحد داخل القائمة المرتبة/غير المرتبة | `<li>Tee</li>`               |
| **`<dl>`** | Kuvauslista (käsitteet ja selitykset) | قائمة تعاريف ومصطلحات                      | `<dl>...</dl>`               |
| **`<dt>`** | Kuvattava termi                       | اسم المصطلح المراد تعريفه                  | `<dt>Kahvi</dt>`             |
| **`<dd>`** | Termin kuvaus/selitys                 | شرح وتفاصيل المصطلح                        | `<dd>Kuuma musta juoma</dd>` |
